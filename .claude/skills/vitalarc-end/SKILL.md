# VitalArc Session Finalization

Finalize a development session for VitalArc iOS app.

## Current State

- **Platform**: !`uname -s | sed 's/Darwin/macOS/;s/Linux/cloud/'`
- **Branch**: !`git rev-parse --abbrev-ref HEAD 2>/dev/null`
- **Recent Commits**: !`git log --oneline --since="6 hours ago" 2>/dev/null`
- **Uncommitted**: !`git status --short 2>/dev/null`

## Steps

### 1. Build check (macOS only)

```bash
[ "$(uname -s)" = "Darwin" ] && xcodebuild -scheme VitalArc -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build 2>&1 | grep -E "(error:|BUILD)"
```

### 2. Gather session stats

```bash
git log --oneline --since="6 hours ago"
git diff --stat HEAD~10 2>/dev/null | tail -3
```

### 3. Update SESSION_LOG.md

Fill in the current session's "Work Completed" and "Session End" sections:

```markdown
### Work Completed
- [Features implemented]
- [Bugs fixed]
- [Commits: hash message]

### Session End
- **Status**: [Summary]
- **Build**: [Passing / Failing / Skipped (cloud)]
- **Commits**: [N] commits
- **Next**: [Priorities for next session]
```

### 4. Update PROJECT_STATUS.md

**IMPORTANT**: Review and update PROJECT_STATUS.md if ANY of these changed:

| Section | Update when... |
|---------|----------------|
| **Last Updated** | Always update to today's date |
| **Feature Status** | Feature moved to Ready, or notes changed |
| **Partially Implemented** | Progress made on incomplete features |
| **Known Issues** | Issues fixed, discovered, or details changed |
| **Codebase Stats** | Files added/removed, significant code changes |

**Check these against session work:**
- Did we fix any known issues? Remove or update them
- Did we complete any partial features? Move to Ready
- Did we discover new issues? Add them
- Did file counts change significantly? Update stats

### 5. Update state file

```bash
BRANCH=$(git rev-parse --abbrev-ref HEAD)
SESSION=$(echo "$BRANCH" | grep -oE '[0-9]+\.[0-9]+' | head -1 | cut -d. -f1)
PLATFORM=$([ "$(uname -s)" = "Darwin" ] && echo "mac" || echo "cloud")

mkdir -p .claude
cat > .claude/session-state.json << EOF
{
  "current_session": ${SESSION:-0},
  "branch": "$BRANCH",
  "status": "completed",
  "ended_at": "$(date -u +%Y-%m-%dT%H:%M:%SZ)"
}
EOF
```

### 5. Commit documentation

```bash
git add SESSION_LOG.md PROJECT_STATUS.md CLAUDE.md .claude/session-state.json 2>/dev/null
git commit -m "docs(session): update session [N] documentation

- [Summary from $ARGUMENTS]

Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>"
```

### 6. Push branch

```bash
BRANCH=$(git rev-parse --abbrev-ref HEAD)
git push -u origin "$BRANCH"
```

### 7. Create PR (optional)

If work is ready for review:

```bash
BRANCH=$(git rev-parse --abbrev-ref HEAD)
gh pr create --base main --head "$BRANCH" --title "<type>(<scope>): <description>" --body "## Summary
- [Key changes]

## Testing
- [ ] Build passes (CI)
- [ ] Manual testing done

---
Generated by /vitalarc-end"
```

Use conventional commit format for PR title.
